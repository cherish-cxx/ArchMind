## 数据流：

打开焦点页：
```
卡片 ↗ → pagesStore.open(uid)
  ├ 已存在同类窗口 → 激活，不新建
  ├ 已有 2 个 → 关闭 openedSeq 最小的
  └ 新建 page { centerUid: uid, hops: 1, positions: {}, ... }
→ classRelations(uid) → applyGraphPatch（全局图，幂等）
→ buildFocusModel(graph, page) → page.positions（不写回节点）
→ 激活 page → viewport flush（rev+1）
```

渲染：
```
graphStore + activePage
  → buildPageModel()
      ├ 累积页：computeRelationBoxes → placeBoxes → routeEdges
      └ 焦点页：buildFocusModel（中心 + 1 跳，按包分扇区）
  → GraphCanvas(pageModel)
```

提问：
```
send → flush(激活页) → Java → Python LLM1 → Java tool → LLM2
→ response.graph → applyGraphPatch（全局）
→ response.uiCommands → 按激活页规则执行
→ 重算 pageModel → 上报激活页
```

## 数据结构

```
// 页面（pagesStore，焦点页坐标只在这里）
{
  id: 'cumulative' | 'focus:<uid>',
  kind: 'cumulative' | 'focus',
  centerUid: null | string,
  hops: 1,
  positions: Map<uid, {x, y}>,   // 焦点页专有
  collapsedPackages: Set<string>,
  view: { scale, x, y },
  selectedUid: null | string,
  openedSeq: number
}

// 框（渲染期，不持久化）
{
  key: '<rel>|<dir>|<成员集合指纹>',
  rel, direction,
  members: string[],   // 完整组
  hidden: string[],    // 唯一归属且未被保护
  shared: string[],    // 别的框也有，保持独立
  sources: string[],
  rect: { x, y, w, h }
}

// 页面模型（GraphCanvas 的唯一输入）
{
  kind, centerUid,
  nodes: [...], boxes: [...], edges: [...], gaps: [...],
  hiddenCount
}
```

如何区分两种视图
不加targePage字段，也不让后端控制页面：
- UiCommand永远作用于执行那一刻的激活页面
- 每条命令带rev，而切换页面会立即flush一次viewport，rev+1；于是为旧页面算出的命令因为cmd.rev< localRev被现有逻辑丢掉。这正好解决这累积页面提问，等答案时切到焦点页的错位
各命令的落法：

| op            | 累积页  | 焦点页                                             |
| ------------- | ---- | ----------------------------------------------- |
| `FOCUS_NODE`  | 现有行为 | 目标在 1 跳内或就是中心 → 选中；不在范围内 → 不切页，给一个"打开 X 的焦点页"按钮 |
| `EXPAND_NODE` | 现有行为 | 已经是 1 跳，忽略                                      |
| `SHOW_PATH`   | 现有行为 | 不适用，提示"路径视图在累积页"                                |
| `CLEAR_VIEW`  | 重置图  | 关闭所有焦点页，回累积页                                    |

后端读得懂"当前是哪种页面"，只用在 prompt 的屏幕摘要里（`_screen_line`），比如"焦点视图，中心 = A，1 跳，可见 6 个"。它不决定页面。将来若要 agent 主动打开焦点页，再加一个 `OPEN_FOCUS` 命令，那是新能力，不是给现有命令加目标字段。

## 异常处理

| 场景                            | 处理                                            |
| ----------------------------- | --------------------------------------------- |
| 打开焦点时 `/class/relations` 失败   | 保留标签页，只画中心，给"重试"；不关窗、不阻塞累积页                   |
| 类没有任何关系                       | 只画中心，文案"没有直接关联的类"；不自动报错                       |
| 框放置找不到空位                      | 按固定角度/半径继续外扩，画布变大；设最大迭代次数后取最外圈候选，保证确定收敛       |
| 选中/焦点节点本来在框里                  | `protected` 让它自动重新可见；不需要手动"拿出来"               |
| 激活的焦点页中心被 `CLEAR_VIEW` 或重分析清掉 | 关闭所有焦点页、回累积页；焦点页描述随图快照一起清                     |
| 提问后切页                         | rev guard 丢弃旧命令；切页时立即上报新 rev                  |
| 旧前端不传新字段                      | Python 默认 `mode='cumulative'`、`hops=1`，行为等同今天 |
| 焦点页可见节点超过 60                  | 前端先按"中心 → 选中 → 环序"截断，后端再截一次并置 `truncated`     |
