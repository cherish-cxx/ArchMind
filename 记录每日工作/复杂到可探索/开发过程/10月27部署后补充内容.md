流程：

用户---前端---java的ask接口---python的ask接口---embed服务---获得dense+sparse---Qdrant两路搜索+合并--top-k点---调用原有工具Neo4j查关系和方法。

打通上述整个流程需要以下这些前提：
qdrant数据库中需要有向量数据
所以需要对数据进行换算，换算成向量；
所以需要embed服务；
同时为了向量的准确性以及项目数据的完整性：
所以需要Neo4j下的所有的类的信息，也就是实现批量类分析

数据写入：
Qdrant需要建表结构，因为向量维度，距离算法，系数向量存在与否都是固定的：
```
PUT http://qdrant:6333/collections/archmind_classes
{
  "vectors": {
    "dense": { "size": 1024, "distance": "Cosine" }
  },
  "sparse_vectors": {
    "sparse": {}
  }
}
```
size:1024s1bge-m3的输出维度。模型更换会导致维度改变，就需要重构集合不能做更改。
再给projectId建一个payload索引，这个索引用来绑定项目Id范围内的内容否则每次都会进行全表扫描

一个类就是一个point：
脚本把每一条embed结果装成这个结构：
```
{
  "id": "3f2a...-uuid5(123:com.x.OrderServiceImpl)",
  "vector": {
    "dense":  [0.0123, -0.0456, ... ],          // 1024 个浮点
    "sparse": { "indices": [2130, 88711],       // token id
                "values":  [0.31, 0.18] }       // 对应权重
  },
  "payload": {
    "projectId": 123,
    "uid": "com.x.OrderServiceImpl",
    "simpleName": "OrderServiceImpl",
    "description": "负责订单创建、取消的核心业务逻辑",
    "filePath": "src/main/java/com/x/order/OrderServiceImpl.java"
  }
}
```

sparse的格式转换
embed 返回的是：

```
{ "2130": 0.31, "88711": 0.18 }
```

Qdrant 要的是两个平行数组：

```
indices = [int(k) for k in sparse.keys()]values  = list(sparse.values())
```

**三个坑**：
- key是字符串，必须转int
- indices必须升序，乱序会被拒
- indices是uint32。

发送upsert
用SDK的话就一行：

```
client.upsert(
    collection_name="archmind_classes",
    points=[PointStruct(id=pid, vector={"dense": d, "sparse": SparseVector(indices=i, values=v)},
                        payload=payload)],
    wait=True,          # 等落盘再返回，便于立刻验证
)
```
底层发的是
```
PUT http://qdrant:6333/collections/archmind_classes/points?wait=true
{ "points": [ {...}, {...}, ... ] }
```
一般64条一批发。量小，一次跑完几十秒。

Qdrant收到之后做什么？
```
HTTP 请求
  ↓
写 WAL（预写日志）—— 先记下来，防止中途崩了丢数据
  ↓
写入 segment（段文件）
  ├─ dense  → 建 HNSW 图，供「近似最近邻」快速找
  ├─ sparse → 建倒排表：token_id → [(point_id, 权重)] 的列表
  └─ payload → 存原样，并维护 projectId 的索引
```
查询时先按projectId过滤，再在剩下的点里做向量搜索。

---
1. Java：补全量读接口（类清单 + 现有 description）
2. Java：对 description 为空的普通类批量生成描述 → 写回 Neo4j
3. Java → Python 脚本：分页返回全量类（含描述）
4. Python 脚本：每个类拼一张卡片文本
5. Python → embed 容器：批量 POST /embed（卡片文本数组）
6. embed 容器内：FlagEmbedding 分词/截断/组 batch → PyTorch 用 bge 权重前向
                 → FlagEmbedding 做 CLS 池化 + 归一化 + sparse 加权
                 → app.py 转成 JSON 列表返回
7. Qdrant：**事先**建集合（dense 1024 + sparse + projectId payload 索引）
8. Python 脚本：sparse dict → indices/values；生成固定 point id；拼 payload
9. Python → Qdrant：批量 upsert
10. 验收：count + 拿一个已知问题检索，看排第一的是不是期望的类
