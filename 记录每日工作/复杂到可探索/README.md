# 复杂到可探索 — AI 代码分析平台

> 一个「上传源码 → 自动分析 → 生成项目认知」的平台：用户上传代码（zip / Git / 本地），系统用 AST + LLM 做扫描、领域建模、架构分析，最终提供项目画像、业务领域地图、架构信息和 AI Agent 问答。

## 未决问题（待定案）

详见 [[复杂到可探索/功能设计.md]] 末尾的「待决问题清单」，关键几项：

| 问题 | 影响 |
| --- | --- |
| 源码存放方式（云临时 vs 本地直读） | file 表 `file_path` 字段语义 |
| 关系型数据库选型（SQLite?） | 持久层实现 |
| AST 工具（JavaParser vs Eclipse JDT） | 代码解析实现 |
| LLM 框架（SpringAI vs LangChain4j） | AI 调用实现 |
| 异步分析机制 | 任务调度、进度上报 |
| 上传安全隐患方案 | 安全性 |
