> **写法约定**
> 1. 每条结论都要能指到**具体文件行**——指不到就是在编。
> 2. 质量属性写**标尺**（系统必须做到什么），不写解法（用什么手段）。

## 1. 项目目标与质量属性

**目标**：面向学生与新接手项目的工作者，尽快理解项目架构与业务核心，提高理解效率，并能对代码修改指出方向与高危地段。

**质量属性**（架构是被这些标尺驱动的）：

| 属性       | 场景（坏事发生）                                           | 可度量                                                   | 证据                                                                                       | 约束了架构的什么                                               |
| -------- | -------------------------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| 性能·延迟    | 用户提问，且 LLM 恰好逼近超时                                  | 端到端最坏 **≤ 70s** 必须返回（网关硬上限）；软目标 P95 ≤ 30s             | `AgentProperties.java:24`、`nginx.conf:19`                                                | 链路上任何超时值改动都必须维持严格递减；LLM 单次调用预算**锁死 25s**               |
| 可靠性·降级   | LLM 超时或不可用，用户提问                                    | 意图识别降级为规则式，主流程**仍返回结果**；导航路径 LLM 调用数 = **0**          | `AgentProperties.java:29`、`AgentController.java:46`                                      | 不能把 LLM 当唯一大脑，必须有确定性兜底；高频操作走零模型成本路径                    |
| 安全性·认证   | 攻击者持**伪造/篡改/过期**的 token 访问 `/api/**`               | 签名、签发者、有效期**任一**不符即拒（0 容忍）                            | `JwtUtil.java:70-84`（校验）、`JwtAuthenticationFilter`（拦截落点）                                 | ①所有公网接口必须过 JWT 过滤器 ②token payload 只签名不加密，**里面不许放敏感信息** |

## 2. 系统上下文图（C4 L1）

```
      ┌─────────────────────────┐
      │  初次接手新项目的人        │   ← Actor（人）
      └────────────┬────────────┘
                   │ HTTPS
                   ▼
      ┌─────────────────────────┐
      │        ArchMind         │   ← 一个框！
      │  内部：前端/Java/Agent   │     （第 3 步再拆）
      │  存储：MySQL/Neo4j/Redis │
      └────────────┬────────────┘
                   │ HTTPS → api.deepseek.com
                   ▼
      ┌─────────────────────────┐
      │    DeepSeek LLM API     │   ← 外部系统（唯一的）
      └─────────────────────────┘
```


|边|方向|协议|用途|挂了会怎样|
|---|---|---|---|---|
|用户 → ArchMind|Actor → 系统|HTTPS|上传项目、看图、提问|正常业务中断（**无降级**）|
|ArchMind → DeepSeek|系统 → 外部|HTTPS|意图识别 + 讲解生成|**降级**：Intent 走规则、讲解走模板，主流程仍返回|
